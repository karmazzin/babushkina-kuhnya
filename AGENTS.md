# Проверки игры

Перед публикацией изменений игровых экранов и переходов выполнять применимые
сценарии из docs/qa/game-regression.md. Проверять каждый способ закрытия окна,
включая крестик и Escape, после победы и проигрыша. После перехода проверять
возможность реального действия игрока; исчезновение диалога само по себе
не означает успешный тест. Не заявлять проверенными сценарии, которые не выполнялись.
