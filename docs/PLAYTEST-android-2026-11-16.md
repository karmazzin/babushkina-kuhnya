# Android: проверка 16 ноября 2026

Версия 1.0.7. Реализация в ветке `codex/android-phase-one`. Публичная PWA и магазины в рамках задачи не обновлялись.

## Подтверждено

- Исходная suite: 223/223; после изменений: 236/236 тестов.
- `npm run build` и `npm run check:release`: актуальные хеши 89 ресурсов.
- Нативный JS-адаптер читает сохранение до начала игры, сохраняет очередь записей, сообщает ошибки, повторяет последнюю запись. Android KitchenSave использует SharedPreferences.commit() на потоке Capacitor.
- Автотесты маршрутов Android Back: помощник, настройки/вложенный сброс, книга/рецепты, результат, все три режима, запрет сворачивания при ошибке записи.
- Браузерная интеграция `node scripts/qa-android-web.mjs`: Pixel 393×851, маленький экран 320×568, альбомный 740×360. Проверены меню/поле без выхода кнопок за экран, реальный ход, прерывание каскада, возврат, перезагрузка и восстановление сохранения, вложенные возвраты, подготовка и отправка JPEG, блокировка старта при ошибке чтения с безопасным повтором.
- В этой проверке использовались настоящий код Capacitor и Android entry, но нативные вызовы имитировались на границе мостика. В ней нет доказательства работы Java/Android WebView.
- Нативный web-пакет не запрашивал внешних ресурсов и не регистрировал service worker. Открытка передаётся файлом, без ссылки на игру.
- PWA на вложенном пути: установка worker, отключение сети, reload из кеша, продолжение партии и выбор блюда проходят.
- Шесть снимков меню/поля в `build/qa-android/`; изображения поля на всех трёх размерах визуально просмотрены.
- Независимый обзор изменений: существенных замечаний нет; отдельные 97 тестов нативных адаптеров/маршрутов прошли.
