# Мобильные приложения «Бабушкина кухня»

Поручение от 16 ноября 2026: сохранить предложенный план и приступить к реализации; Android — фаза 1, iOS — фаза 2.

## Решение
Одна игровая база HTML/CSS/JS, PWA на GitHub Pages и локальная Android-оболочка Capacitor. Все ресурсы входят в APK, включая открытки и музыку; первый запуск не требует сети. Альтернативы: оставить только PWA (нет установочного Android-пакета) или переписать игру на другом движке (несоразмерно цели минимальных усилий). Выбран предложенный в чате Capacitor.

## Фаза 1 — Android
- Нативный проект и воспроизводимая сборка APK для проверки на телефоне; подготовка AAB без публикации.
- Хранилище Preferences, последовательная запись текущего формата, явная обработка ошибок; никаких миграций старых сохранений. Прогресс PWA не переносится автоматически.
- Системная кнопка «Назад»: отмена текущего выбора, безопасный выход модального окна, возврат по экранам; из главного меню сворачивание только после успешной записи.
- Пауза звука и отмена жеста при сворачивании, восстановление после возврата.
- Открытки через системное меню отправки файлов, без ссылки на игру и без широкого доступа к файлам телефона.
- Нативная сборка не регистрирует service worker, не скачивает игру с GitHub Pages и не показывает установку PWA/обновления браузера.
- Название, локальные иконки и стартовый экран; учёт системных панелей и обеих ориентаций.
- Тесты логики и сборки, проверка интерфейса; реальный Pixel обязателен перед выпуском игрокам. Эмулятор не объявлять физическим телефоном.

## Границы
Без аккаунтов, рекламы, аналитики, платежей и облачных сохранений. Без регистрации аккаунтов магазинов, публикации и изменения GitHub Pages в этой задаче. Ключ подписи публичного выпуска и окончательный идентификатор магазина потребуют отдельного выбора перед публикацией. Технический идентификатор первой сборки: `io.github.karmazzin.babushkinakuhnya`.

## Фаза 2 — iOS
После Android-проверки: iOS-проект, Xcode, native storage/share/lifecycle, safe area и звук на iPhone, privacy manifest, TestFlight, затем подготовка App Store. Сейчас iOS-проект и зависимости платформы не создаём.

## Приёмка
Android APK устанавливается и запускается без сети с первого раза. Завершённый ход восстанавливается после закрытия процесса. Все три режима и коллекции сохраняются. Отмена вложенного окна ведёт по видимой кнопке; после выхода можно продолжить полезное действие. PWA и её относительные пути/обновления проходят прежние проверки. Подтверждённые проверки отделяются от непроверенного оборудования и публикации.
