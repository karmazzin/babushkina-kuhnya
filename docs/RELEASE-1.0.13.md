# Android 1.0.13 — кандидат для RuStore

16 ноября 2026. Последний полученный `origin/main`: `cf29406` (PWA 1.0.12). Объединён с Android-оболочкой и локальными отчётами в ветке `codex/rustore-release-1-0-13`. Публикация в GitHub Pages, отправка в RuStore и изменение приложений на телефоне не выполнялись.

## Что включено

Все коммиты main до cf29406: огород и награды, доставка чая, обновлённое меню/коллекции, улучшения свайпов и отображения блюд, сохранение достижений и локальные резервные записи. Android-оболочка сохранена: полностью локальные ресурсы, нативные сохранения, системная отмена, JPEG-шаринг.

При объединении адаптированы несовместимые участки: нативное хранилище теперь поддерживает весь набор записей прогресса через SharedPreferences.commit(); системная кнопка Back возвращает из огорода вместо удалённой книги; покупка огорода не объявляется успешной до подтверждения записи, при отказе доступен повтор. setMany атомарен для одного снимка; одна операция saveProgress может поставить в очередь несколько снимков, flush ждёт итогового подтверждения. Сброс прогресса на телефоне не выполнялся.

Добавлена повторяемая команда `npm run android:release`. Для неё требуются JDK/SDK и переменные `ANDROID_KEYSTORE`, `ANDROID_KEY_PASSWORD_FILE`, `ANDROID_KEY_ALIAS`; при этой сборке дополнительно задан `ANDROID_CERT_SHA256` для проверки нужного сертификата. Пароли передаются файлом, не содержимым командной строки. Новые ключи не создаются. Порядок настройки — в [ANDROID.md](ANDROID.md).

- `npm run build`, `npm run check:release`: версия 1.0.13, сборка `336604c9f273a0e6`, 93 ресурса.
- `npm test`: **262/262**.
- Регрессионные тесты сначала воспроизвели несовместимость многочастного сохранения и Android Back, затем прошли после интеграции.
- `scripts/qa-android-web.mjs`: 393×851, 320×568, 740×360 — ход, прерывание/возобновление, вложенные возвраты, подготовка шаринга, отказ чтения и повтор, размеры поля/кнопок; дополнительно огород, отказ записи покупки и повтор, сохранение покупки после перезагрузки и следующий полезный ход. Нативный мост в этой браузерной проверке имитируется.
- PWA на вложенном пути: service worker, перезагрузка без сети и следующее действие.
- Снимки меню, поля и огорода сохранены в `build/qa-android/`; выборочно визуально просмотрены портретное меню, малое поле и альбомный огород.
- Gradle `assembleRelease`: BUILD SUCCESSFUL, release-проверки не отключались.
- `apksigner verify`: подпись подтверждена; сертификат сравнен с ожидаемым.
- `zipalign -c -P 16 4`: успешно.
- `verify-android-apk.py`: все 92 игровых файла совпадают с подготовленным Android-пакетом, нет worker/remote server.
- Независимый read-only обзор интеграции не нашёл блокирующих проблем.

**Ограничение:** Pixel не подключён (`adb devices -l` пуст). Версия 1.0.13 и новый Java-метод setMany ещё не проверены на физическом телефоне. Проверки 1.0.7 не считаются доказательством проверки 1.0.13. Перед фактической отправкой на модерацию рекомендуется проверить свежий APK на устройстве, включая сохранение огорода, холодный запуск и обновление.
