# Проверка баланса и игровых переходов — 15 ноября 2026

Версия 1.0.2, сборка `3eb0d3463f2ebfde`, ветка `codex/game-balance`. Реализация согласованного плана завершена. Публикация в эту задачу не входит.

## Что реализовано

- Поле 7×8, пять активных равновероятных блюд из каталога десяти. Новое блюдо заменяет одно прежнее на уровнях 19, 31, 43, 55 и 67; состав начатой партии сохраняется.
- 42 составленных уровня, далее ограниченные по сложности волны по 12 уровней. Максимум две цели, разнесённые группы тарелок.
- При создании каждой партии движок проверяет все 64 области стартовых помощников с полными каскадами и сохранённым состоянием генератора. Поле, допускающее мгновенную победу помощником, отбрасывается. Один чайник напрямую затрагивает не более половины начальных тарелок.
- По одному заряду каждого помощника в начале, максимум три, максимум один заработанный заряд каждого вида за обычный ход. Применение помощника не тратит ход и не выдаёт заряды. При нуле ходов оставшиеся заряды доступны; можно добровольно завершить попытку.
- Подсказки через девять секунд учитывают оставшиеся цели; после трёх действий без прогресса могут предложить помощника с областью действия.
- Двенадцать уникальных иллюстрированных рецептов с порциями, количествами ингредиентов и шагами. Открытия: 6, 18, 30, 42, 54, 66, 78, 90, 102, 114, 126, 138. Повторное прохождение не выдаёт повторную награду.
- Четыре типа ежедневных заданий, 24 разных открытки, отдельный режим «Без спешки» с бесконечными ходами. Три режима сохраняются независимо.
- Итоги выделяют выполнение целей и награду. Добавлены полка рецептов, прогресс до следующего рецепта и объяснение первого заработанного помощника.

## Дорелизное правило

По прямому уточнению пользователя проект поддерживает только текущий формат. В `AGENTS.md` закреплён запрет на миграции и поддержку прошлых схем и игровых правил до отдельного решения о первом релизе для игроков.

Удалены перебор старых ключей сохранений, номера схем и правил, восстановление отсутствующих полей по прежним правилам, старые цели по очкам, прежний API подсказок, миграция коллекций и соответствующие тесты/QA-сценарии. Текущий ключ — `babushkina-kuhnya:progress`. Остались проверки повреждения текущего сохранения и защита от перезаписи прогресса другой вкладкой при обновлении.

## Проверка настоящего интерфейса

Браузерные проверки выполнены в размерах 320×568, 390×844, 393×851 (размер Pixel) и 568×320. Проверены поле из 56 клеток, меню, цели, помощники, книга уровней, полка рецептов, ингредиенты, шаги и итоговые окна. Основные элементы помещаются без прокрутки; новые блюда различимы.

- После победы: переход к следующему уровню и настоящий следующий ход.
- При нуле ходов: сохранение, перезагрузка, продолжение, выбор/отмена помощника, победа помощником и следующий уровень.
- Добровольное завершение: Escape сохраняет попытку; подтверждение открывает проигрыш; повтор запускает новую партию, следующий ход работает.
- Обычный ход действительно выдаёт заряд и первое объяснение. Подсветка области помощника не применяет его автоматически.
- Режим «Без спешки»: настоящий ход сохраняет бесконечный запас; переключение режимов сохраняет отдельные партии.
- Награда шестого уровня: рецепт, переходы по ингредиентам и шагам, возврат в книгу, следующий рецепт на уровне 18.
- Открытка: новая иллюстрация, просмотр и скачивание изображения. Формирование файла для отправки без ссылки на установку покрыто тестами.
- Финальная сборка показала готовность к офлайн. После полного выключения QA-сервера страница перезагрузилась из кэша, восстановила уровень 67, показала все новые изображения и позволила сделать ход; затем выполнен ход в режиме «Без спешки». Предупреждений о сохранении и ошибок консоли не было.

Снимки финальной сборки: `screenshots/recipe-320.jpg`, `screenshots/foods-pixel.jpg`.

Физический телефон, установленная PWA на нём, звук через его динамик и отправка в конкретные приложения-мессенджеры этим браузерным прогоном не проверены. Плейтест с бабушкой остаётся следующим источником обратной связи о сложности и удобстве.

## Независимый просмотр и принятые решения

Выполнен один независимый просмотр всей ветки. Замечание о миграции старых наград снято прямым указанием пользователя отказаться от совместимости; этот код и тесты удалены. Для проигрыша ежедневного задания добавлен фактический прогресс целей и регрессионная проверка. Неисправленных замечаний ревью в согласованном объёме нет.

Решения реализации, в порядке принятия:

1. Отдельный Git worktree создан в папке проекта после недоступного ответа встроенного инструмента. Это сохранило изоляцию параллельной работы; следствие — отдельная локальная папка и ветка.
2. Перед изменением интерфейса включены завершённые исправления обновлений из основной ветки. Их проверки сохранены; риск интеграции покрыт общими тестами и офлайн-прогоном.
3. Прежнее решение о продолжении наград для перенесённых коллекций отменено последним указанием пользователя. До релиза действует только текущий формат; перенос прежних тестовых сохранений не предусмотрен.
4. Отложенные ревьюером браузерные и визуальные проверки выполнены здесь. Оценка удобства на физическом телефоне и ощущений бабушки остаётся открытой; автоматические победы не заменяют её участие.
