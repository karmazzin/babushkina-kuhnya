# Локальная релизная Android-сборка

Поручение от 16 ноября 2026: подготовить release APK и проверить на Pixel без публикации. Пользователь выбрал отдельную установку рядом с текущей debug-игрой, чтобы не менять её прогресс.

## Идентификаторы и подпись

- Основной APK: `io.github.karmazzin.babushkinakuhnya`.
- Проверочный APK: `io.github.karmazzin.babushkinakuhnya.releasecheck`, название «Кухня — проверка релиза». У него отдельное хранилище; прогресс основной игры не переносится и не меняется.
- Оба APK собираются задачей `assembleRelease`, без включения отладки. В проверочном варианте меняются только applicationId и отображаемое название.
- Новый локальный ключ, отличный от debug: `/Users/antonkarmazin/Documents/ChatGPT/Бабушкина кухня/.android-tools/signing/kitchen-release.p12`, alias `kitchen-release`.
- Пароль хранится локально в соседнем `kitchen-release.password`, не выводится в отчёты. Каталог имеет права 700, файлы ключа и пароля — 600; `.android-tools/` исключён из Git.
- Ключ создан для локальных подписанных сборок. Решение о ключах Google Play App Signing/upload key и окончательном идентификаторе магазина остаётся отдельным этапом.

Ключ и пароль нужно сохранить в надёжной резервной копии вне этого компьютера до распространения APK. Потеря ключа лишает возможности выпускать обычные обновления локально подписанной установки. В облако ключи не загружались.

Основной release APK нельзя установить поверх прежнего debug APK из-за разных сертификатов. Для проверки на Pixel применяется отдельный проверочный APK; основная установка не удаляется. Правила подписи: [Android Developers](https://developer.android.com/studio/publish/app-signing).

## Артефакты и повторение

Версия игры остаётся 1.0.7: игровые файлы не менялись, выпуск игрокам и публикация не выполняются. APK сохраняются в `build/releases/`. Временный сборочный проект и журнал находятся в `build/release-qa/`; сборка не меняет канонический applicationId исходников.

Локальная сборочная процедура: `python3 build/release-qa/prepare.py`. Она использует существующие SDK/JDK, Gradle и node_modules основного checkout; создаёт копию Android-проекта, выполняет `assembleRelease`, подписывает APK через `apksigner` и проверяет подпись. При повторении используется уже существующий ключ, новый не генерируется. Эта процедура привязана к текущему Mac; для CI потребуется отдельная настройка защищённого хранилища секретов.
