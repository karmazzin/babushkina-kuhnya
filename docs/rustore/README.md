## Проверка соответствия

- npm run build + npm run check:release: 93 ресурса, сборка 336604c9f273a0e6.
- npm test: 262/262 пройдены, 16 ноября 2026.
- APK: 92 локальных web-ресурса побайтово совпадают с подготовленной Android-сборкой; внешнего server.url и PWA service worker нет.
- apksigner: действительны v2/v3, ожидаемый ранее сохранённый сертификат.
- zipalign -c -P 16 4: успешно.
- minSdk 24 (Android 7), targetSdk 36. Android 8+ входит в поддерживаемый диапазон. Проверка каждого устройства/версии ОС не проводилась.
- Разрешения APK: INTERNET и собственное signature-разрешение DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION. Нет контактов, камеры, микрофона, геолокации, уведомлений, рекламного ID или общего доступа к файлам.
- По исходникам: нет сервера, аккаунтов, SDK аналитики/рекламы/платежей/push. Сохранения в закрытых SharedPreferences; allowBackup=false. Поделиться: временный файл открытки через FileProvider/системный выбор приложения.
- Лицензии музыки и эффектов находятся в dist/assets/audio/LICENSES.txt, авторство доступно в настройках. Иллюстрации генерировались для проекта; промпты — docs/*prompts.json. Юридическая уникальность названия/товарных знаков отдельно не проверялась.
- Полноценная офлайн-игра и системный шаринг дают дополнительную функциональность для WebView по п.8.2 требований RuStore. Это аргумент соответствия, не гарантия модерации.
- Pixel на момент подготовки не подключён. Именно 1.0.13 не прошла физический smoke-test и обновление на устройстве; прежние проверки 1.0.7 не заменяют эту проверку.

## Перед аппрувом

1. Дозагрузить APK, иконку, три изображения; дождаться обработки APK и устранить выявленные кабинетом ошибки. Черновик текста уже сохранён.
2. Проверить 1.0.13 на Pixel, сохранив текущую debug-партию. Не удалять установленное приложение: debug и release имеют разные подписи. Для проверки использовать отдельный пакет/заранее согласованный перенос; основной APK магазина — только canonical package выше.
3. При необходимости добавить публичную политику: privacy-draft.md описывает фактическое поведение Android. Раздел о сроке хранения обращений поддержки требует решения владельца; текст ещё не опубликован. Не декларировать отсутствующие сбор данных/интеграции.
4. Проверить страны распространения и итоговую карточку. Не включать TV: управление с пульта не реализовано и не проверено.
5. Получить аппрув на конкретный APK, описание, изображения и декларации. Только затем отправлять на модерацию. После одобрения вручную публиковать по разрешению владельца.

## Рекомендации

Первый выпуск оставить бесплатным, без рекламы, аналитики и push. Начать со статистики RuStore и обращений поддержки. Диагностику JavaScript/native ошибок и игровую аналитику рассматривать отдельной задачей с пересмотром политики и декларации. Не добавлять SDK ради присутствия SDK.
