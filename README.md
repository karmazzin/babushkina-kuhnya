# Бабушкина кухня

Автономная мобильная PWA «три в ряд»: поле 7×8, 24 хода, без таймера.

## Книга и помощники
- 3 главы по 6 уровней: завтрак, воскресный обед, гости к чаю.
- Цели: очки, одно блюдо, два блюда, очки вместе с блюдом.
- После всех шести уровней главы открывается семейный рецепт. Следующие тетради повторяют главы с умеренным, ограниченным ростом сложности.
- Скалка собирает выбранный ряд; чайник — область 3×3 (по краям обрезается).
- Один заряд каждого помощника на новую партию. 4+ в ряд дают скалку, пересечение Т/Г — чайник. Максимум 3 заряда каждого. Помощники не тратят ход и не создают новые заряды.
- Выбор помощника → подсветка области → «Применить»; можно отменить.
- Подсказка после 9 секунд покоя; касание ускоряет каскад.

## Локально
Требуется Node.js 22+. Зависимостей нет.

```sh
npm test
npm start
```

Адрес: http://localhost:4187

Проверка вложенного пути GitHub Pages:
```sh
PORT=4189 BASE_PATH=/babushkina-kuhnya/ npm start
```

## GitHub Pages
Исходники предназначены для **приватного** репозитория. Для Pages из приватного репозитория нужен подходящий тариф GitHub (Pro/Team/Enterprise). Сам сайт должен оставаться публичным, без авторизации для игрока.

Workflow `.github/workflows/pages.yml` проверяет тесты и публикует только `dist/` при push в `main`. В Settings → Pages выберите GitHub Actions. Все URL относительные: проектный путь поддерживается, включая манифест и service worker.

Не загружайте `.openai/`, `.env`, локальные токены или пользовательские сохранения. Никаких ключей для работы игры не нужно.

## Офлайн и сохранения
Первый запуск — с интернетом. Дождитесь «Готово к игре без интернета», затем установите приложение из меню браузера. Все изображения, музыка, звуки, рецепты и код кешируются локально. Обновления активируются после закрытия старых вкладок; текущая партия не прерывается.

Прогресс хранится на устройстве. Старые партии на очки продолжаются без смены цели. В настройках есть экспорт и импорт JSON-сохранения с проверкой и подтверждением замены. Разные домены не могут автоматически читать сохранения друг друга: перенос требует файла. Очистка данных браузера удаляет локальный прогресс.
