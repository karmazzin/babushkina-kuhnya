# Бабушкина кухня

Автономная мобильная PWA «три в ряд»: поле 7×8, 24 хода, без таймера.

## Книга и помощники
- 3 главы по 6 уровней: завтрак, воскресный обед, гости к чаю.
- Первые 12 уровней составлены вручную: одно блюдо, два блюда, тарелки, тарелки вместе с блюдом. Тарелки впервые появляются на уровне 4; совпадение или помощник убирает их с фиксированных клеток.
- Уровни 13 и дальше сохраняют прежние цели и главы.
- После всех шести уровней главы открывается семейный рецепт. Следующие тетради повторяют главы с умеренным, ограниченным ростом сложности.
- Скалка собирает выбранный ряд; чайник — область 3×3 (по краям обрезается).
- Один заряд каждого помощника на новую партию. 4+ в ряд дают скалку, пересечение Т/Г — чайник. Максимум 3 заряда каждого. Помощники не тратят ход и не создают новые заряды.
- Выбор помощника → касание поля. Область видна под пальцем, применение — при отпускании. Повторное нажатие помощника отменяет выбор; отпускание за полем не тратит заряд.
- Свайп сопровождается движением блюда и подсветкой соседа; также работают два касания и клавиатура.
- Подсказка после 9 секунд покоя; касание ускоряет каскад.

Не загружайте `.openai/`, `.env`, локальные токены или пользовательские сохранения. Никаких ключей для работы игры не нужно.

## Офлайн и сохранения
Первый запуск — с интернетом. Дождитесь «Готово к игре без интернета», затем установите приложение из меню браузера. Все изображения, музыка, звуки, рецепты и код кешируются локально. Новая версия загружается в фоне при запуске, возврате в игру и периодической проверке. Закрывать вкладки не требуется: кнопка «Обновить игру» дожидается конца хода, сохраняет партию и перезагружает только выбранную вкладку. В настройках доступна ручная проверка. При ошибке сохранения переключение блокируется.

Прогресс хранится на устройстве. Старые партии на очки продолжаются без смены цели. Ручного импорта и экспорта в интерфейсе нет. Разные домены не могут автоматически читать сохранения друг друга. Очистка данных браузера удаляет локальный прогресс.

## Угощение дня и мягкая сложность
Отдельный короткий уровень на 16 ходов по местной дате устройства. Повтор доступен без ограничений; одна открытка за дату, без серий и штрафов за пропуски. Незаконченный вчерашний уровень можно продолжить. Коллекция содержит 12 рисунков, затем датированные повторные издания. Коллекция и обе партии сохраняются на устройстве.

С пятого уровня цели крупнее, поздние тарелки распределены по полю, лимит постепенно снижается до 22 ходов. Новая партия получает максимум один заряд каждого помощника за ход с каскадами. Начатые партии сохраняют прежние правила. Сохранение переносится из v1 в отдельный ключ v2, защищённый от записи старой вкладки; дальнейший прогресс старых вкладок с новой версией не объединяется.

Проверки: `docs/PLAYTEST-daily-2026-11-15.md`.

Открытки — 12 полноценных сгенерированных иллюстраций с пожеланиями. В награде и коллекции есть «Поделиться открыткой» (системное меню при поддержке передачи файлов) и «Сохранить картинку» (JPEG для ручного прикрепления). Иллюстрации кешируются для офлайна. Игровые номера и даты не входят в отправляемую картинку. Промпты и инструмент генерации: `docs/postcard-prompts.json`.

## Игровой экран — иллюстрированные предметы
На поле оставлены небольшой номер уровня, цели на подносе и ходы на тарелке. Большой логотип и постоянные подсказки убраны; правила доступны по «?». Скалку и чайник заменяют растровые иллюстрации, повторное нажатие отменяет выбор помощника. Ассеты и новый CSS включены в офлайн-кеш.

Проверки и ограничения: `docs/PLAYTEST-visual-2026-11-15.md`; промпты: `docs/gameplay-art-prompts.json`.

## Подготовка обновления
После любых изменений `dist/`: `npm run build`, `npm run check:release`, `npm test`. Сборка вычисляет SHA-256 каждого ресурса и версию релиза. CI отклоняет устаревшие хеши. Установщик использует проверенные неизменившиеся файлы из прежнего кеша, качает остальные с ограничением параллелизма и повторными попытками; неполная версия не активируется. Две предыдущие версии кеша сохраняются для старых вкладок и повторного использования. При конфликте несохранённой партии с более новым сохранением другой вкладки запись и обновление блокируются, показывается предупреждение.

Проверки: `docs/PLAYTEST-reliable-updates-2026-11-15.md`.

Версия в настройках берётся из `package.json.version`; ниже мелко показан код сборки открытой страницы. Для следующего выпуска: `npm run release:patch` (повышает 1.0.1 → 1.0.2 и собирает релиз). Повторная `npm run build` сохраняет выбранный номер.

(4,16 → 0,56 МБ вместе). Все 24 открытки остаются JPEG для отправки в мессенджеры;

офлайн-подготовка сохранена: музыка и открытки по-прежнему скачиваются в фоне;
для полной автономности нужно дождаться сообщения о готовности. Общий объём dist
уменьшился с 39,67 до 25,98 МБ. Это размеры файлов, а не замер времени загрузки.

Проверено: сборка и целостность релиза; 210 тестов, включая задержку регистрации,
офлайн-ресурсы, обновления и сохранения; в Chrome — первый запуск, готовность офлайн,
игровой ход, перезагрузка и продолжение партии, размеры 393×851 и 851×393.
Все открытки просмотрены на контактном листе. Физический телефон, прослушивание

## Надёжная загрузка на медленном соединении — 16 ноября 2026

Загрузчик читает ответ потоком и прерывает попытку только после 60 секунд без
новых данных (включая ожидание ответа сервера). Общего лимита на длительность
файла больше нет. Остаются три попытки и SHA-256 перед записью целого файла
в кеш; ранее проверенные файлы используются повторно. Незавершённый файл при
повторе скачивается заново, побайтовое докачивание не реализовано.

Во время передачи крупных файлов worker сообщает о прогрессе не чаще раза
в 10 секунд. Ожидание установки в интерфейсе продлевается только сообщениями
от устанавливаемого worker; медленная передача больше не считается ошибкой
через две минуты. Применение обновлений по-прежнему требует действия игрока
и успешного сохранения партии.

Проверено: 215 тестов, включая 80-секундную передачу по виртуальным часам,
зависший ответ/тело, повторные попытки, целостность, heartbeat и чужие worker.
Chrome на локальном стенде с общим каналом 1,5 Мбит/с и задержкой ответа 100 мс
скачал полный пакет за 157,5 секунды. После отключения сервера проверены
перезагрузка из кеша и запуск новой партии. Физический телефон не проверялся.
